📊 Customer Churn Analysis – Meridian

📌 Project Overview

This project focuses on analyzing customer churn for Meridian using PostgreSQL to identify churn patterns, high-risk customer segments, and key factors associated with customer attrition.

The analysis uses a customer-level dataset containing demographic, financial, engagement, transaction, and customer service information.

🔎 Churn Analysis Tasks

Calculated the overall customer churn rate
Analyzed churn across different age groups
Analyzed churn across income segments
Compared churn rates across card types
Evaluated the relationship between payment delays and churn
Analyzed churn based on support satisfaction
Examined churn risk scores and churn probability
Identified high-risk customer segments
Compared segment-level churn rates against the overall portfolio baseline
Analyzed customer engagement and financial indicators associated with churn
